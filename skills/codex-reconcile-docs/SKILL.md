description: Audit or fix requested drift between project documentation, configuration, and code.
---

Explicit user instructions take precedence over these guidelines.

Compare relevant README setup commands, referenced paths, version sources, release notes, and specifications against current code. Focus on the requested area or changes since the supplied baseline. Separate confirmed mismatches from unavailable external facts.

If fixes are requested, update local documentation to the verified behavior and validate commands or links as appropriate. Do not infer permission to post comments, close issues, or change remote roadmaps. Return concrete corrections and unresolved evidence gaps; do not schedule unsolicited recurring reconciliation.
