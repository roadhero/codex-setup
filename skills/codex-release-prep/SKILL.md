---
name: codex-release-prep
description: Prepare a requested release with version consistency, notes, and validation.
---

Explicit user instructions take precedence over these guidelines.

Find the real version source, previous tag, release workflow, and distribution channel. Prepare the requested version and concise behavior-oriented notes. Check source/tag/artifact parity and required tests. Include platform-specific signing, migration, and rollback checks only when applicable.

Separate local preparation from publishing, remote tags, store submission, or deployment. Proceed with those only when the user has authorized them. Preserve configured Git identity. Report prepared artifacts, verification evidence, and exact remaining steps without creating a mandatory approval ceremony for already authorized work.
